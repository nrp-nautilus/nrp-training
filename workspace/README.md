# CLARIPHY — workspace

Files attendees open or run during the training.

| File | What it is |
|---|---|
| `notebooks/` | The lesson notebooks — open them on the NRP training hub |
| `requirements.txt` | Python packages for running the notebooks on your own machine; install them into a virtual environment (see the Setup page) |
| `jfc_setup.sh`, `jfc_setup.ps1` | One-shot setup for the JFC agent exercise (macOS/Linux/WSL, and Windows) |
| `check.sh` | `bash check.sh <lesson number>` — checks your progress in a lesson |
| `yamls/` | Kubernetes or Helm YAML files, if a lesson needs them |
